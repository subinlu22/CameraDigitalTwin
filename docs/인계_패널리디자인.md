# 인계 — 로봇 조종 패널 · 렌더 룩 콘솔 리디자인 (여유될 때)

> 11/19 작성. Claude Code나 Codex 누가 이어받아도 이 문서만 보고 시작할 수 있게.
> 목표: 따로 뜨는 두 창의 모양을 **Unity 안 패널(TwinSidePanel)과 같은 느낌**으로 맞추기. 기능·안전 규칙은 그대로.

## 1. 지금 구조

| 창 | 위치 | 띄우는 법 | 화면 |
|---|---|---|---|
| 로봇 조종 패널 | `Tools/so101_bridge/` | exe·에디터 화면 아래 [로봇 조종 패널] 버튼, 또는 `panel_start.bat` | `panel.py`가 로컬 웹 서버(127.0.0.1:8765) + Edge 앱 창. 화면 = `web/index.html`·`style.css`·`app.js`·`robot3d.js`(three.js 3D) |
| 렌더 룩 콘솔 | `Tools/render_console/` | 화면 아래 [렌더 룩 콘솔]·F6, 또는 `start.bat` | `console.py` 로컬 웹 + Edge 앱 창. 화면 = `web/index.html`·`style.css`·`app.js` (글꼴 `web/fonts/SUIT-Variable.ttf`) |

- 로봇 조종 패널의 본체는 **`core/bridge.py`**(30Hz, 화면 없음). 화면은 0.1초마다 `/api/status`로 값을 받고, 버튼은 `/api/cmd`로 명령을 보냄 → UDP 5061 명령과 똑같이 `bridge.handle()`로 감.
- **흰 팔 안전 규칙은 전부 브리지 안에 있음** (범위 자르기·속도 제한·0.3초 끊김 정지·벨트 충돌 검사·비상 정지). 화면은 명령만 보냄 → 리디자인해도 안전 코드는 건드리지 않기.
- 메시지 형식: `docs/so101_messages.md` (5060 리더 각도 / 5061 명령 / 5062 응답·상태 / 5063 목표 자세), `docs/render_look_messages.md` (5070/5071).

## 3. 방법 두 가지 (수빈이 고르기)

| | A. 웹 화면 그대로, CSS만 바꾸기 | B. Unity UI로 다시 만들기 |
|---|---|---|
| 하는 일 | `web/style.css`의 색·글꼴·모양을 위 표로 맞춤. 필요하면 `index.html` 칸 배치만 조정 | 브리지는 화면 없이(`headless.py`) 켜고, 패널 기능을 Unity UGUI 창으로 만듦. Unity가 UDP 5061 명령 / 5062 상태로 조작 (이미 `UnityToFollowerGUI`가 같은 길을 씀) |
| 장점 | 빠름(반나절), 안전 코드 그대로, 3D(three.js) 그대로 | 진짜 같은 느낌, exe 하나 안에 패널까지 → "유니티 없이 exe 하나로" 메시지에 더 맞음 |
| 단점 | 웹이라 Unity와 완전히 같진 않음 | 하루 이상. 포트 찾기·연결·연습 모드·비상 정지·힘 빼기를 Unity에서 다 다시 만들어야 함. 3D 미리보기는 Unity 장면이 대신 |
| 주의 | — | 브리지(파이썬)는 여전히 필요. Unity UI는 명령만 보내고, 안전 규칙은 브리지에 둠 |

추천: 시간 없으면 A부터. B는 포폴 이후 여유 있을 때.

## 4. 확인하는 법 (흰 팔 없이)

- 패널: `panel_start.bat` → **연습 모드 켠 채로** 버튼만 눌러 보기 (흰 팔은 안 움직이고 값만 계산). 팔을 연결해서 실제로 움직이는 확인은 학교에서, 움직이기 전에 무엇이 어떻게 움직이는지 설명하고 수빈 확인받기.
- 콘솔: `start.bat` → Unity 플레이(또는 exe) 켠 상태에서 룩 카드·재질을 눌러 반영되는지.
- Unity 쪽 버튼은 `Assets/Scripts/RobotPanelButton.cs`, `Assets/RenderLookConsole/Runtime/RenderLookPanel.cs`.

## 5. 규칙 (이 프로젝트 공통)

- 코드·주석·커밋에 개인 이름·이메일 넣지 않기.
- 기능 하나마다 커밋, 한국어 커밋 메시지, 커밋 전 바뀐 파일 목록 보여 주기.
- 보류 중인 `Assets/Scripts/TwinSidePanel.cs` 수정(로봇 없이 연습 글자 굵게)은 건드리지 않기.
- 새 스크립트는 핵심 흐름을 쉬운 말로 짧게 설명하기.
