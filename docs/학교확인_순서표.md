## 2. 자세 재생 (5e82a75 확인 못 했던 것 포함)

## 3. 유니티 안 뚜껑 집기 (연습용 뚜껑)
- [x] 2번 재생 중 "집기 전(벌림)" 다음에 **손가락 사이에 뚜껑이 나타남**
- [x] 콘솔 `[연습 뚜껑] 손가락 사이에 놓음 (손가락 끝 n cm 위 …)` 확인

- 안 될 때
  - "⚠ 손가락 끝이 뚜껑보다 높아서" → 집는 자세가 너무 높음: 그 자세의 어깨 들기/팔꿈치를 조금 내려서 다시 저장

  - "집게 아래에 면이 없음" → 탁자·벨트에 콜라이더가 있는지
