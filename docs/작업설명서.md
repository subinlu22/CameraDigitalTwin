## 0. 작업 전/후 꼭 하는 것 (체크리스트)

**작업 전**
1. Unity 아래쪽 **Console** 창을 열어서(`Window > General > Console`) 빨간 에러가 없는지 본다.
2. 큰 작업 전에는 먼저 커밋(11번)해두면 망쳐도 되돌릴 수 있다.

**작업 후**
1. **Ctrl + S** 로 씬 저장 (Hierarchy 위 씬 이름 옆에 `*` 가 없어지면 저장된 것).
2. Console 에 빨간 에러 0개.
3. **Play** 눌러서 7번 순서대로 한 번 돌려보기.
4. 커밋 (11번).

> 절대 건드리지 말 것
> - `Assets/_Recovery` 폴더 (Unity가 비상용으로 만든 복구 파일)
> - `Library`, `Temp`, `Logs` 폴더 (Unity가 자동으로 만드는 캐시)
> - 로봇팔(SO101) 관련: `Assets/URDF`, `so101_new_calib_camera` 프리팹, `HoldRobotPose` / `DroopRobotPose` / `RobotJointTester` 스크립트 — 따로 조정해둔 값이 많아서 이 설명서 작업과 섞지 않는다.

## 2. 재질·텍스처 바꾸기

### 2-1. Substance Painter 에서 내보내기
1. `File > Export Textures`
2. Output Template: **Unity Standard (Metallic)** 선택
3. 결과 파일 3장: `..._AlbedoTransparency`, `..._MetallicSmoothness`, `..._Normal`
   - Roughness 따로 변환할 필요 없음 (MetallicSmoothness 의 알파 채널에 매끈함이 들어감)
4. 파일을 `Assets/Textures` 폴더에 넣는다 (탐색기에서 끌어다 놓기 또는 같은 이름으로 덮어쓰기).

### 2-2. 텍스처 임포트 설정 (Project 창에서 텍스처 클릭 → Inspector)

| 텍스처 | Texture Type | sRGB (Color Texture) | Max Size |
|---|---|---|---|
| AlbedoTransparency | Default | **켬** | 4096 |
| MetallicSmoothness | Default | **끔** | 4096 |
| Normal | **Normal map** | (자동) | 4096 |

설정을 바꾼 뒤 Inspector 아래 **Apply** 꼭 누르기.

### 2-3. 재질에 연결 (예: `Assets/Textures/blinn1.mat`)
1. Project 창에서 재질 클릭
2. Shader: `Standard`
3. **Albedo** 칸 왼쪽 네모에 AlbedoTransparency 끌어다 놓기, 오른쪽 색은 흰색
4. **Metallic** 칸에 MetallicSmoothness, Source: `Metallic Alpha`
5. **Smoothness** 슬라이더: 지금 **0.9** (금속 광택). 너무 반짝이면 0.7~0.8
6. **Normal Map** 칸에 Normal
7. Height Map 은 비워둔다

### 2-4. FBX 재질 슬롯 연결 (모델을 새로 내보냈을 때)
1. Project 창에서 `Assets/Models/cam_s_merge.fbx` 클릭
2. Inspector 위쪽 **Materials** 탭
3. **Remapped Materials** 목록에서 각 슬롯에 재질을 끌어다 놓기
   - `blinn1` → `Assets/Textures/blinn1.mat`
   - `pasted__blinn9` → `Assets/Materials/Belt_Cloth.mat`
4. **Apply**
5. 벨트 천 모양이 바뀌었다면 → `Tools > 벨트 > 천 메시(UV) 다시 만들기` (5-3번)
6. 링라이트 모양/위치가 바뀌었다면 → `Tools > 링라이트 > 발광 링 만들기 (다시 만들기)` (4번)

### 2-5. 분홍색 / 회색으로 나오면
- **분홍색** = 재질의 셰이더를 못 찾음 → 재질 Shader 를 `Standard` 로
- **회색, 무늬 없음** = 텍스처 칸이 비었음 → 2-3번 다시
- 씬에서 오브젝트 클릭 → Inspector 의 **Mesh Renderer > Materials** 목록에 `None` 이 있으면 재질을 끌어다 넣기

## 3. 조명 · 반사 · 라이팅 굽기

### 3-1. 조명 세기 바꾸기
1. Hierarchy 에서 조명 클릭 (예: `Directional Light (1)`)
2. Inspector **Light > Intensity** 숫자 바꾸기
3. Game 창을 보면서 조절 → Ctrl + S

현재 값: `Directional Light` 1 / `Directional Light (1)` 0.8 / `Spot Light` 1.5 / `RingLight_Glow/RingSpot` 5
> 바닥이 하얗게 날아가 보이면 보조 조명(`Directional Light (1)`)부터 줄인다.

### 3-2. Reflection Probe (금속이 금속답게 보이게)
이미 `Reflection Probe` 오브젝트가 장비를 덮도록 있다. 새로 만들 때만:
1. `GameObject > Light > Reflection Probe`
2. Inspector:
   - Type: **Baked**
   - **Box Projection** 체크
   - Box Size: 장비를 덮을 만큼 (지금 1.8 × 1 × 1.8)
   - Resolution 256, HDR 체크
3. 반사에 찍힐 물체는 Static 이 필요: 물체 클릭 → Inspector 오른쪽 위 **Static** 옆 화살표 → **Reflection Probe Static** 체크
   (지금 `cam_s_merge`, `flow` 와 그 아래 전부 체크되어 있음)

### 3-3. 라이팅 굽기 (Generate Lighting)
조명이나 Reflection Probe, 물체 위치를 바꾼 뒤에는 다시 구워야 반사가 맞는다.
1. `Window > Rendering > Lighting`
2. 아래쪽 **Generate Lighting** 클릭 → 오른쪽 아래 진행 막대가 끝날 때까지 기다리기
3. 결과는 `Assets/Scenes/SampleScene/` 폴더(LightingData, ReflectionProbe-0.exr 등)에 저장됨 → **이 폴더도 같이 커밋**

> 링라이트를 단 뒤로는 아직 다시 굽지 않았다. 금속에 링 빛까지 비치게 하고 싶으면 한 번 Generate Lighting 하고 커밋.

## 4. 링라이트 발광

실제 장비처럼 링 안쪽 아래에 하얗게 빛나는 띠 + 아래로 벨트를 비추는 조명.

### 4-1. 메뉴로 만들기 (추천)
1. `Tools > 링라이트 > 발광 링 만들기 (다시 만들기)`
2. Hierarchy 에 `RingLight_Glow` 가 생김 (안에 `GlowBand`, `RingSpot`)
3. **Ctrl + S**

- 링 모델(`cam_s_merge/cam/pTorus1`) 위치/크기를 자동으로 읽어서 맞춘다 → 링을 옮기거나 FBX를 바꾼 뒤에는 이 메뉴만 다시 누르면 됨
- 지우기: `Tools > 링라이트 > 발광 링 지우기`
- 되돌리기: Ctrl + Z
- 다시 만들어도 `RingLight_Glow.mat` 에서 조절한 띠 밝기는 그대로 유지됨 (조명 RingSpot 세기는 기본값 5로 다시 생김)

### 4-2. 밝기 조절

| 바꾸고 싶은 것 | 어디서 |
|---|---|
| 띠가 빛나는 정도 | Project `Assets/Materials/RingLight_Glow.mat` 클릭 → **Emission** 색 칸 클릭 → Intensity |
| 벨트 위 밝은 원 | Hierarchy `RingLight_Glow/RingSpot` → Light > **Intensity** (지금 5), **Spot Angle** (지금 80, 넓을수록 크게 퍼짐) |
| 그림자 | RingSpot → Shadow Type (Soft / No Shadows) |

### 4-3. 손으로 만들고 싶을 때 (원리)
1. Maya 에서 링 안쪽 아래에 맞는 얇은 고리(띠)를 하나 모델링 → FBX로 내보내기
2. Unity에서 새 재질 (`Project 창 우클릭 > Create > Material`) → Shader `Standard` → **Emission** 체크 → 색 흰색, Intensity 2 정도
3. 띠 모델에 재질 넣기, Mesh Renderer 의 **Cast Shadows: Off**
4. `GameObject > Light > Spotlight` 를 링 바로 아래에 두고 Rotation X = 90 (아래를 보게), Range 0.5, Intensity 5
> 참고: Built-in 렌더 파이프라인에는 기본 "빛 번짐(Bloom)"이 없다. Game 화면에서는 띠가 하얗게만 보이고, 번짐은 8번 스튜디오 렌더 메뉴가 사진에만 입혀준다.

## 5. 컨베이어 벨트 (속도 · 천 돌아가기)

### 5-1. 벨트 속도 — 두 군데를 같은 값으로

| 어디 | 칸 이름 | 뭘 움직이나 |
|---|---|---|
| Hierarchy `DigitalTwin` → **DigitalTwinReceiver** | **Belt Speed** | 카메라 메시지로 생긴 뚜껑 (화면에 보이는 뚜껑은 이 값) |
| Hierarchy `cam_s_merge/BeltSurface` → **BeltMover** | **Speed** | 천 무늬 스크롤 + 물리로 올린 물체 |

현재 둘 다 **0.015** (m/초). 반으로 줄이려면 둘 다 0.0075.
> Play 중에 바꾸면 바로 보이지만 Play를 끄면 원래대로 돌아간다. 마음에 드는 값을 찾았으면 **Play를 끈 뒤 다시 입력**하고 Ctrl + S.

### 5-2. 천 무늬 스크롤 (BeltScroll)
`cam_s_merge/Conveyer_Belt2` 에 붙어 있음.

| 칸 | 뜻 |
|---|---|
| Belt Mover | 속도를 따라갈 BeltMover (BeltSurface 를 끌어다 놓기) |
| Tile Length | 무늬 한 장이 벨트 위에서 차지하는 길이. **0.05** (천 메시 만들 때 값과 같아야 속도가 맞음) |
| Reverse | 무늬가 뚜껑과 반대로 흐르면 체크 |

BeltMover 의 **Is Running** 체크를 끄면 천도 멈춘다.

### 5-3. 천 메시가 왜 따로 있나 / 다시 만들기
- FBX 원본의 천은 장비 전체와 텍스처 한 장을 같이 써서, 그대로 무늬를 흘리면 장비 전체 무늬가 같이 흘러버린다.
- 그래서 천 메시를 복사해서 "벨트 둘레를 따라 한 바퀴 이어지는 UV"를 새로 붙인 `Conveyer_Belt2_Loop.asset` 을 쓴다.
- **FBX를 다시 내보내서 벨트 천 모양이 바뀌었으면**: `Tools > 벨트 > 천 메시(UV) 다시 만들기` → Ctrl + S
- 천 무늬 그림을 바꾸고 싶으면: `Assets/Textures/Belt_Green_Cloth.png` 를 같은 이름의 다른 그림으로 바꾸기 (위아래·좌우가 이어지는 반복 무늬여야 끊김이 안 보임)

## 6. 뚜껑 견본 (이름 규칙 · 1↔3 바뀜 고치기)

### 6-1. 이름 규칙
`cam_s_merge/number` 아래 9개. **색 앞글자 + 숫자**
- `w` = 흰색(white), `b` = 파랑(blue), `r` = 빨강(red)
- 예: `b1` = 파랑 1번 뚜껑

카메라 프로그램이 `{"color":"blue","digit":"1"}` 을 보내면 DigitalTwinReceiver 가 `b1` 이라는 이름의 견본을 복사해서 벨트에 올린다.
→ **이름과 실제 뚜껑에 찍힌 숫자가 다르면 엉뚱한 뚜껑이 나온다.**

### 6-2. 이름이 맞는지 확인하는 법
1. Hierarchy 에서 `b1` 클릭 → Scene 창에서 테두리로 표시되는 뚜껑의 숫자를 본다
2. 또는 Scene 창 오른쪽 위 축 표시(Gizmo)의 **Y(초록)** 를 눌러 위에서 내려다보고 하나씩 클릭해서 확인
> 예전에 1↔3 이 바뀌어 있었던 이유: Maya 에서 이름을 붙일 때 착오. 지금은 Unity 씬에서 이름을 맞바꿔 고쳐 둠. **FBX를 새로 내보낼 땐 Maya 쪽 이름도 고쳐서 내보내기** (안 그러면 FBX 다시 가져올 때 또 바뀔 수 있음).

### 6-3. 이름 바꾸기
1. Hierarchy 에서 뚜껑 클릭 → **F2** → 새 이름 입력 → Enter
2. 두 개를 맞바꿀 땐 임시 이름을 거쳐서: `b1 → tmp`, `b3 → b1`, `tmp → b3`
3. Ctrl + S → 7번 방법으로 확인

## 7. Play로 동작 확인하기

1. 위쪽 **▶ (Play)**
2. Game 창 오른쪽에 **"오늘 통계"** 패널이 떠야 정상 (DashboardUI 가 Play 할 때 코드로 만듦 → Play 전에는 안 보이는 게 정상)
3. Console 에 이런 줄이 보이면 정상:
   - `[연동] 뚜껑 견본 9개 등록: ...`
   - `[연동] UDP 수신 대기 시작 (포트 5053)`
4. 카메라 없이 뚜껑 생성 테스트: Hierarchy `DigitalTwin` 클릭 → Inspector 의 **DigitalTwinReceiver** 이름 옆 **⋮** → `테스트: 빨강1 생성` / `테스트: 파랑2 불량`
   - 벨트 위에 해당 뚜껑이 나오고, 통계 숫자가 올라가고, 화면 테두리가 초록/빨강으로 번쩍하면 정상
5. 확인 끝나면 다시 **▶** 눌러 Play 끄기

> Game 창에 UI 가 안 보이면: Game 창 왼쪽 위 **Display** 가 `Display 1` 인지 확인.

## 9. 움짤·영상 만들기

### 9-1. 녹화
방법 A — **Unity Recorder** (화질 제일 좋음)
1. `Window > Package Manager` → 왼쪽 **Unity Registry** → `Recorder` 검색 → **Install**
2. `Window > General > Recorder > Recorder Window`
3. **+ Add Recorder > Movie** → Format MP4, Output Resolution `FHD 1080p`
4. **Start Recording** → 자동으로 Play 가 켜지며 녹화 → 원하는 만큼 찍고 Stop
5. 파일 위치: 프로젝트 폴더/Recordings

방법 B — 화면 녹화
- **Win + Alt + R** (Xbox Game Bar) 로 녹화 시작/정지 → `동영상\캡처` 폴더
- 또는 OBS

### 9-2. 영상 → 움짤 변환 (ffmpeg)
명령 프롬프트에서 영상이 있는 폴더로 이동 후:
```bash
ffmpeg -ss 3 -t 8 -i 영상.mp4 -vf "fps=20,scale=960:-1:flags=lanczos" -c:v libwebp -q:v 65 -loop 0 -an 움짤.webp
```
- `-ss 3` = 3초부터, `-t 8` = 8초 길이
- `scale=960:-1` = 가로 960px (세로는 비율대로)
- webp 가 GIF 보다 훨씬 작고 선명 → 사이트에는 webp 추천

GIF 가 꼭 필요할 때:
```bash
ffmpeg -ss 3 -t 8 -i 영상.mp4 -vf "fps=15,scale=800:-1:flags=lanczos,split[a][b];[a]palettegen[p];[b][p]paletteuse" -loop 0 움짤.gif
```

사이트용 mp4 로 용량 줄이기:
```bash
ffmpeg -i 원본.mp4 -vf scale=1920:-2 -c:v libx264 -crf 23 -preset slow -movflags +faststart -an 웹용.mp4
```

영상 포스터(재생 전 미리보기 사진) 뽑기 — 24초 지점:
```bash
ffmpeg -ss 24 -i 웹용.mp4 -frames:v 1 -vf scale=1280:-1 포스터.webp
```

### 10-2. 카드 내용 고치기 (`index.html`)
`Ctrl + F` 로 `data-title="Camera Digital Twin"` 검색 → 그 `<article ...>` 줄의 속성들:

| 속성 | 뜻 | 쓰는 법 |
|---|---|---|
| `data-video` | 상세보기 맨 위 영상들 | 쉼표로 여러 개. mp4 경로 또는 유튜브 주소. **맨 앞이 맨 위** |
| `data-video-poster` | mp4 재생 전 미리보기 사진 | 경로 1개 |
| `data-video-captions` | 영상 아래 설명 | **영상 순서대로 쉼표로**. 설명 안에 쉼표(,) 쓰면 안 됨 (· 사용) |
| `data-render` | 대표 이미지 | 경로 1개 |
| `data-note` | 대표 이미지 설명 | |
| `data-extra` | 추가 사진 묶음 | 아래 문법 |

`data-extra` 문법:
```
#묶음이름,사진경로::설명,사진경로::설명,=,사진경로::설명,#다음묶음,...
```
- `#이름` = 소제목 (Unity / Modeling / Real 등)
- `경로::설명` = 사진 1장과 그 아래 설명
- `=` = 여기서 줄 바꾸기 (사진 줄 배치를 직접 나눌 때)
- 사진 높이는 자동으로 맞춰짐. webp 움짤도 같은 방법으로 넣으면 됨

지금 Camera Digital Twin 의 Modeling 묶음 (윗줄 2장, 아랫줄 2장):
```
#Modeling,assets/projects/twin_model_01_hero.webp::...,assets/projects/twin_model_05_angle.webp::...,=,assets/projects/twin_model_04_side.webp::...,assets/projects/twin_model_03_belt.webp::...
```

## 12. 문제 생겼을 때 (FAQ)

**Q. 재질이 분홍색이다** → 2-5번.

**Q. Play 했는데 대시보드 UI 가 없다** → Play 전에는 원래 안 보임. Play 중에도 없으면 Game 창 Display 1 확인, `DigitalTwin` 의 DashboardUI 컴포넌트 체크(켜짐) 확인.

**Q. 파랑1 을 보냈는데 3 이 나온다** → 6번 (견본 이름 확인).

**Q. 천이 안 움직인다** → BeltMover `Is Running` 체크, Speed 가 0 이 아닌지, `Conveyer_Belt2` 의 BeltScroll 에 `Belt Mover` 칸이 비어 있지 않은지. 천 무늬가 이상하면 `Tools > 벨트 > 천 메시(UV) 다시 만들기`.

**Q. 뚜껑과 천 속도가 다르다** → 5-1번 두 값을 같게.

**Q. 금속이 밋밋하다 / 반사가 이상하다** → 3-3번 Generate Lighting 다시.

**Q. Visual Studio 에서 ▶(시작) 누르면 오류** → Unity 스크립트는 VS 에서 혼자 실행되는 프로그램이 아님. 실행은 Unity 의 Play 로 하고, VS 는 코드 편집용(디버깅할 땐 "Unity에 연결"). 카메라 검사 프로그램(C#)은 그 프로젝트의 솔루션을 따로 열어서 실행.

**Q. Unity 가 UDP 를 못 받는다** → 카메라 프로그램의 UnityPort 와 DigitalTwinReceiver 의 Port(5053)가 같은지, 방화벽에서 Unity 허용했는지.

**Q. Claude(AI)가 Unity 를 못 만진다** → Unity 에서 `Window > MCP for Unity` → **Start Server** (HTTP, 포트 8080). 프로젝트 폴더의 `.mcp.json` 이 이 서버를 가리킨다.

**Q. 메뉴(Tools > ...)가 안 보인다** → Console 에 빨간 에러가 있으면 스크립트가 컴파일이 안 된 것 → 에러부터 해결.

**Q. 커밋에 이상한 파일이 잔뜩 있다** → `Library`, `Temp`, `Renders` 등은 .gitignore 로 빠져 있어야 정상. `Assets/_Recovery` 는 올리지 않기.
